# Spam Prediction

Проект **Spam Prediction** предоставляет веб-сервис для определения, является ли сообщение спамом или не спамом ("ham"). Он включает функции обработки текстов, классификации сообщений с помощью предобученной модели и CRUD-операции для работы с сообщениями. 

---

## 📚 Описание

Сервис:
- Определяет категории сообщений (`spam` или `ham`) с использованием обученной модели (AutoKeras + TensorFlow).
- Предоставляет интерфейс API для работы с данными сообщений.
- Включает методы предобработки текста, построение моделей и их развёртывание.

1. **Клонирование репозитория**

## 💻 Зависимости

Используемые технологии:
- **AutoKeras** v1.1.0
- **TensorFlow** v2.15.1
- **Keras-NLP** v0.5.1
- **FastAPI** для разработки API
- **Uvicorn** для запуска веб-сервера
- **NLTK** для обработки естественного языка
- **Seaborn** и **Matplotlib** для визуализации данных
- **Pandas** и **NumPy** для работы с данными

Установить зависимости можно командой:
```bash
pip install autokeras==1.1.0 tensorflow==2.15.1 keras-nlp==0.5.1 fastapi uvicorn python-multipart seaborn nltk pandas matplotlib
```

## 🔧 Запуск приложения

1. **Подготовьте модель**

   Убедитесь, что файл предобученной модели `spam_classifier.keras` присутствует в папке проекта.  
   Если его нет, вы можете обучить модель, используя ноутбук `Model_spam_AutoKeras.ipynb` и сохранить её.

2. **Запустите сервер**

   Используйте **Uvicorn** для запуска приложения:
   ```bash
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```
### Параметры команды запуска

- `--reload`  
  Автоматически перезапускает сервер при каждом внесении изменений в код. Удобно для разработки.

- `--host 0.0.0.0`  
  Позволяет развёртывать сервер локально или предоставлять к нему доступ из локальной сети.

- `--port 8000`  
  Устанавливает порт для доступа к приложению. Можно заменить `8000` на любое свободное значение порта.

  ## Доступ к сервису

После запуска сервер будет доступен по адресу:

- **Основной URL**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Swagger-документация**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **Альтернативная документация OpenAPI**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## CRUD для работы с сообщениями

- **Получить список сообщений**: `GET /data`
- **Добавить сообщение**: `POST /data`
- **Найти сообщение по ID**: `GET /data/{id}`
- **Обновить сообщение**: `PUT /data/{id}`
- **Удалить сообщение**: `DELETE /data/{id}`

## 📐 Файловая структура

- `Model_spam_AutoKeras.ipynb`  
  Ноутбук для обучения модели.

- `Spam_prediction.ipynb`  
  Веб-сервис для определения категорий сообщений.

- `spam_classifier.keras`  
  Предобученная модель.

- `spam_model.py`  
  Функции загрузки и предсказания модели.

- `preprocess.py`  
  Функции предобработки текста.

- `models.py`  
  Определение структур данных с Pydantic.

- `prediction.py`  
  API для предсказания категорий сообщений.

- `crud.py`  
  CRUD API для работы с сообщениями.

- `main.py`  
  Основной файл для запуска FastAPI.
